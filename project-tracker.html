Settings

Theme and colour customisation

Choose a base theme, then customise its colours below. Each theme keeps its own saved palette.

Colours

These override the base theme. Each theme remembers its own set, so switching back restores what you saved.

Column views

A view controls which columns appear on the Projects and Issues tables. Switch between them from the View dropdown on either page. Every view can be edited, renamed and deleted — duplicate Full view to start your own. The last remaining view cannot be deleted.

Jira status sync

Jira Cloud will not accept API calls from a page like this one: the browser blocks the response because Atlassian does not allow cross-origin requests to your Jira site, and there is no server here to make the call instead. So the status is brought across by copy and paste, which needs no API token and stores no credentials.

Your data file

Keeps your data in a real file on disk instead of relying on browser storage. Once connected, every change is written straight to that file, and the tracker reloads from it automatically when you open it. This is the reliable option if this browser will not keep your data.

Not connected — relying on browser storage.
Save to this browser

Saves your data into this browser and then reads it back to prove it was kept. The tracker saves automatically after every change, so this is a way to check that saving is actually working rather than something you need to do routinely.

Spreadsheet export

Export the current data as CSV for Excel, Jira or reporting, or bring a spreadsheet back in. Import merges with what is already here and asks what to do about anything that already exists.

Duplicate names

Finds clients, owners and reporters stored with inconsistent capitalisation or spacing, and merges them onto the most-used spelling.

Local backups

Snapshots are taken when you open the app and every 15 minutes while you work. They are stored in this browser's local database, which is not limited to the small localStorage quota — but it is still only this browser, so keep exporting JSON for real backups.
